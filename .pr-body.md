## Summary

Adds a new hands-on lab (Lab 05) that teaches learners how to build an instruction-driven agent using the redesigned "new" Copilot Studio experience. The lab complements the existing classic-experience labs by showing how instructions, prebuilt actions, and autonomous reasoning replace the topic authoring canvas.

## Changes

- Added Lab 05, "Create an agent using the new Copilot Studio experience," a 30-minute, level-200 exercise.
- Included a scenario, learning objectives, high-level steps, and prerequisites (Entra ID account, Copilot Studio license/trial, and a Power Platform environment/solution from the ILT Setup lab).
- Added a "Key concept" comparison table contrasting the classic topic-tree model with the new instruction-driven model.
- **Exercise 1** — Switch to the new Copilot Studio experience and review the redesigned navigation (Home, Agent Ops, Chat, Agents, Workflows; no Topics section).
- **Exercise 2** — Create a Contoso IT support agent from a natural-language description, answer clarifying questions, review auto-generated instructions, and refine them with explicit guidelines (self-service password reset, ticket-collection rules, and a Send an email prebuilt action).
- **Exercise 3** — Test the agent in the Preview tab, inspect the reasoning trace, run three test scenarios (password reset, hardware failure, ticket submission), and iterate on instructions before publishing.
- Added a summary that contrasts the reduced authoring effort of the new experience with the workflow-based tool authoring in Lab 03.

## Files changed

- `Instructions/Labs/05-create-agent-new-experience.md` — New lab file (204 lines) covering the end-to-end new Copilot Studio experience: switching interfaces, creating an instruction-driven agent, adding a prebuilt action, and testing autonomous reasoning.
